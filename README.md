# Tavos Marketplace System

Bachelor thesis project focused on the design and development of a flexible online marketplace system with dynamic category configuration and listing management functionality.

## Features

- User registration and authentication
- Google authentication support
- Listing creation and management
- Dynamic category-specific fields
- Category-based filtering
- Administrative dashboard
- Category and field configuration
- Listing archive support

## Technologies

### Backend
- ASP.NET Core Web API
- Entity Framework Core
- ASP.NET Identity

### Frontend
- Blazor WebAssembly
- MudBlazor

### Database
- Microsoft SQL Server

## Architecture

The system follows a layered client-server architecture:

- API Layer
- Application Layer
- Domain Layer
- Infrastructure Layer
